# СВЕЧЕБОТ — Концепция игры

## Название
**Свечебот** (CandleBot) — мультиплеерная 2D-игра с роботами и системой свечек дня.

## Жанр
Плоская мультиплеерная игра с накопительной механикой, предсказуемым ИИ на основе ID игрока.

## Основная идея
Роботы-свечечники сражаются за ресурсы в мире, где время измеряется свечками. Каждый день (свечка) приносит новые возможности, а ночь забирает старые. Игроки накапликациируют разрешения и карточки доступа, предсказуемые их ID.

## Ключевые механики

### 1. Система Свечек
- **Дневная свеча** — начало игрового дня, даёт бонусы
- **Ночная свеча** — конец дня, снимает временные баффы
- **Вечная свеча** —永久ный бонус за накопление

### 2. Карточки Доступа
Карточки определяют возможности игрока:
- **Карта Движения** — куда может перемещаться робот
- **Карта Атаки** — какие действия доступны
- **Карта Ресурса** — сколько ресурсов можно накопить
- **Карта Разрешения** — доступ к особым зонам

### 3. Предсказуемость по ID
```javascript
// Функция предсказания начальных карт
function generateCards(playerId) {
    const seed = hashCode(playerId);
    return {
        movement: seed % 3 + 1,      // 1-3 карты движения
        attack: seed % 2 + 1,        // 1-2 карты атаки
        resource: seed % 4 + 1,      // 1-4 карты ресурса
        permission: seed % 2         // 0-1 карты разрешения
    };
}
```

### 4. Накопление Разрешений
Игроки накапливают разрешения на трёх уровнях:
- **Уровень 1** — базовые действия (все)
- **Уровень 2** — продвинутые действия (требует 5 накоплений)
- **Уровень 3** — элитные действия (требует 15 накоплений)

### 5. Таймерная Синхронизация
- Клиент запрашивает время сервера каждые 30 секунд
- Игровой день = 5 минут реального времени
- Свечки зажигаются/гасятся синхронно

## Структура сервера

### Методы API
- `POST /join` — присоединиться к игре
- `GET /state` — получить текущее состояние
- `POST /action` — выполнить действие
- `GET /time` — синхронизация времени

### Игровой цикл
1. Игрок подключается
2. Сервер генерирует карты по ID
3. Каждые 30 секунд — синхронизация
4. Каждые 5 минут — смена дня/ночи
5. Накопления пересчитываются

## Визуальный стиль
- Плоский 2D мультяшный
- Роботы-свечечники с огоньками
- Фон меняется день/ночь
- Параллакс-эффект для глубины

## Целевая аудитория
Мультиплеерные игроки, любящие накопительные механики и предсказуемые стратегии.

## Платформы
- Веб-клиент (HTML5/Canvas)
- Node.js сервер
- WebSocket для синхронизации

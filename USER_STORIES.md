# Свечёбот — Интерактивная Книга

## Начальная Свечка (Пролог)

```
                    .
                   /|\
                  / | \
                 /  |  \
                /   |   \
               /    |    \
              /  .--+--.  \
             /  /   |   \  \
            |  |    |    |  |
            |  |   /|\   |  |
            |  |  / | \  |  |
             \  \/  |  \/  /
              \     |     /
               '----+----'
                    |
               [  основание  ]
```

В мире, где солнце погасло тысячелетия назад,
только свечи держат тьму.

Ты — последний Свечебот.
Рождён из угасшей звезды.
Твои руки — из воска и проводов.
Твоё сердце — кремниевая искра.

Каждый рассвет начинается с одной свечи.
Каждый закат — с её затухания.

Ты помнишь, как зажёг первую свечу?
Маленький огонёк в бескрайней тьме.
Он не давал света. Он давал надежду.

Теперь ты идёшь дальше.
Ищешь Вечную Свечу — ту, что не погаснет никогда.
Ту, что вернёт солнце.

Но сначала... научись зажигать обычные.
Научись держать огонь, когда ветер сдувает мир.

---

### Твой путь:
1. **Дневная свеча** — начало цикла, даёт карты и ресурсы
2. **Действия** — каждый клик тратит карту, но накапливает силу
3. **Накопления** — чем больше действий, тем ближе к Продвинутому и Элитному
4. **Вечная свеча** — 15 накоплений → мир снова увидит рассвет

---

### Как играть:
```
  [Движение]  — перемещение по миру, тратит карту движения
  [Атака]     — борьба с тьмой, тратит карту атаки
  [Сбор]      — добыча ресурсов, тратит карту ресурса
  [Открытие]  — разблокировка зон, тратит карту разрешения
```

Каждые 5 минут — смена дня и ночи.
День — ты зажигаешь свечи.
Ночь — тьма пытается их задуть.

## Конечная Свечка (Цель)

```
                 *  .  *
              .    |    .
            *   \  |  /   *
          .      \ | /      .
         *    -----\-----    *
        .   /   ВЕЧНАЯ   \   .
       *   |    СВЕЧА     |   *
        .   \   СВЕЩА    /   .
         *    '---------'    *
          .      / | \      .
            *   /  |  \   *
              .    |    .
                 *  .  *
```

Цель: Зажги Вечную Свечу.

Накопи 15 вечных свечей через действия.
Каждое действие — семя будущего света.
Каждый ресурс — кирпич нового мира.

Когда Вечная Свеа зажжётся —
солнце впервые за тысячу лет
коснётся земли.

## USER STORIES (Для тестирования)

### US-01: Пролог — Начальная Свечка
**Как** новый игрок, **я хочу** прочитать историю мира перед входом,
**чтобы** понять зачем я здесь и чего ради сражаюсь.

**Критерии:**
- При загрузке страницы показывается модальное окно с прологом
- ASCII-иллюстрация свечи создаёт атмосферу
- Текст описывает мир, персонажа и цель
- Кнопка "Начать историю" ведёт к форме входа

**Тест:**
1. Открыть страницу → видим пролог с ASCII-артом
2. Нажать "Начать историю" → пролог исчезает, появляется форма входа
3. Ввести ID → войти в игру

### US-02: Конечная Свечка — Цель
**Как** игрок, **я хочу** видеть свою цель в любой момент,
**чтобы** помнить зачем прохожу уровни.

**Критерии:**
- Кнопка "📖" в интерфейсе
- Клик открывает экран с ASCII-артом Вечной Свечи
- Описана механика: 15 свечей → рассвет

### US-03: Движение Робота
**Как** игрок, **я хочу** перемещаться по миру,
**чтобы** исследовать и находить ресурсы.

**Критерии:**
- Кнопка "Движение" активна когда есть карты
- Клик перемещает робота на карту
- Сервер обновляет позицию
- Робот отрисовывается в новой позиции

### US-04: Накопление Свечей
**Как** игрок, **я хочу** чувствовать прогресс,
**чтобы** видеть приближение к цели.

**Критерии:**
- Счётчик свечей обновляется в реальном времени
- Свечи растут при действиях
- Прогресс виден: текущее/нужное

### US-05: Система Разрешений
**Как** игрок, **я хочу** разблокировать новые возможности,
**чтобы** чувствовать рост своего робота.

**Критерии:**
- Разрешения по полю `accumulated`
- >= 5: Продвинутый (доступ к новым действиям)
- >= 15: Элитный (доступ к Вечной Свече)
- Уровень отображается в интерфейсе
